# 0021: ユーザー依頼と合意に基づく ADR 更新を許可する

- Status: Accepted
- Amended-By: 0022

ADR 0019 は `grill` で根拠や採用判断を確認し、`scribe` で反映する責務分離を置いた。一方で、ユーザーが ADR 作成・更新を明示依頼した場合や、会話上で方針変更・採用判断が明確に合意された場合まで、追加の提案 step を必須にすると実際の作業指示と重複する。

`scribe` は、ユーザーの明示依頼、または会話上の合意で方針変更・採用判断が確認できる場合、ADR の作成、`Accepted` 作成、状態更新、relationship metadata の反映を実行してよい。合意が曖昧な場合だけ、`grill` で根拠や採用判断を確認してから `scribe` で反映する。

この判断は ADR 0019 の責務分離を置き換えず、`grill` が必要な境界を「合意が曖昧な場合」に限定する。
