# Basic Design Format

`docs/BASIC_DESIGN.md` を作成・更新する時に使う。
要件を満たす全体方針、責務分担、主要構成を置く。

## 手順

- 要件、受入条件、制約から全体方針と責務分担を整理する。
- 詳細な処理順や実装手順は入れすぎず、詳細設計へ送る。
- 代替案は、実際に検討価値がある場合だけ残す。

## Rules

- 対象の `FR-*` と対応付ける。

## Template

```markdown
# 基本設計

## FR-001: [機能または要件領域名]

### 設計方針

[要件を満たすための基本方針。]

### 構成と責務

- `[component]`: [責務。]

### 基本設計項目

- `BD-001`: [要件を満たすための主要な設計判断または構成要素。]

### データ / 状態

- [扱う主な data、state、保存先。]

### 利用者 / システムフロー

1. [主要な流れ。]

### 未確認事項

- [未確認事項。]
```
