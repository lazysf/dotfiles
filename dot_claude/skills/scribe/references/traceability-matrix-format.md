# Traceability Matrix Format

必要に応じて、request folder 内 artifact の対応関係を一覧化する。

## Rules

- `AC-*` は必ず `REQ-*` に紐づける。
- `BD-*` は対応する `REQ-*` / `AC-*` を明示する。
- `DD-*` は対応する `BD-*` / `AC-*` を明示する。
- `TASK-*` は対応する `DD-*` / `AC-*` を明示する。
- `TC-*` は対応する `AC-*` / `TASK-*` を明示する。
- 対応が確認できないものは推測で埋めず、`TBD` または `N/A` と理由を残す。

## Template

```markdown
# Traceability Matrix

| 要求事項  | 受入条件 | 基本設計 | 詳細設計 | タスク     | 検証結果 | テストコード | 状態      | 備考                               |
| --------- | -------- | -------- | -------- | ---------- | ------------ | ------------ | --------- | ---------------------------------- |
| `REQ-001` | `AC-001` | `BD-001` | `DD-001` | `TASK-001` | `TC-001`     | `TBD`        | `planned` | [未作成、対象外、不明などの理由。] |
```

## 状態

- `draft`: まだ問い詰め中
- `planned`: 実装前計画まである
- `implemented`: 実装済み
- `verified`: 確認済み
- `deferred`: 後回し
