# Lua Best Practices

`Lua` で返り値契約、`local` の閉じ方、テーブル設計に迷うときの判断補助。

## エラー処理の目安

- 既存が `nil, err` を返すなら、その契約を崩さない。
- `error()` は回復不能で、呼び出し側が例外前提の箇所に限定する。
- `pcall` は境界や不安定な外部呼び出しに絞り、内部処理へ広げすぎない。

## 状態とデータ構造

- グローバルを増やさず、`local` を既定にする。
- 設定値は散在させず、既存の設定テーブルや引数経由に寄せる。
- 動的にキーを増やすテーブルは、呼び出し側から見て形が追える範囲に留める。
- 述語を返す関数名は `is_` や `has_` など、近傍実装の形に寄せる。

## 避けたいこと

- `local` で閉じられる値を無理由にグローバルへ出すこと
- 返り値契約を変えるのに、呼び出し元の追従確認をしないこと
- テーブルを過剰に入れ子にして、呼び出し側の読みやすさを落とすこと
