# Phase Quality Analysis

品質分析工程の入口をそろえ、改善対象と検証観点を整理する。

## 入力

- 品質課題
- 計測情報または観測事実
- 制約

## uses

- `core-quality-analysis`

## 出力

- `quality_target`
- `bottleneck_or_risk`
- `improvement_scope`
- `verification_focus`

## 完了条件

- どの品質特性を改善するか説明できる
