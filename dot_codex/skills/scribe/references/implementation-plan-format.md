# Implementation Plan Format

`docs/IMPLEMENTATION_PLAN.md` を作成・更新する時に使う。
詳細設計から実装スライス、確認入口、作業境界を置く。

## Rules

- 実装計画用フォルダは作らず、`docs/IMPLEMENTATION_PLAN.md` を使う。
- 実装結果、日報、作業ログは混ぜない。
- 対象の `FR-*` と対応付ける。
- `TASK-*` は実行しやすく、対応する確認方法が分かる粒度にする。
- 未確認事項は `未確認事項` に残す。
- 実装計画の責務外の内容は書かない。

## Template

```markdown
# 実装計画

## FR-001: [機能または要件領域名]

### スコープ

- [今回実装すること。]

### 非スコープ

- [今回実装しないこと。]

### 実装スライス

1. [実装のまとまり、順序、依存。]

### タスク

- `TASK-001`: [作業内容、完了条件、対応する確認方法。]

### 確認方法

- [test、lint、build、手動確認、比較観点。]

### リスク

- [失敗しやすい点、既存挙動への影響。]

### 未確認事項

- [未確認事項。]
```
