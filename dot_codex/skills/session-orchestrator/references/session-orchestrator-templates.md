# Session Orchestrator Templates

`session-orchestrator` の補助資料。
長めのセッションを、小さな進行単位に切るための型を置く。

## 基本テンプレート

```markdown
## 現在地

- [探索中 / 要件整理中 / 実装準備中 / 実装中 / 検証中 / レビュー前]

## 次の最小スライス

- [次に進める最小の変更単位]

## 途中確認ポイント

- [確認を挟む条件]

## 検証方法

- [test / lint / build / 手動確認]

## 終了条件

- [今回の区切り]
```

## 使い方の目安

- `plan-product` のあと、まだ進め方が広いときに使う。
- `plan-architect` ほど重くせず、セッションの切り替え条件だけを置きたいときに使う。
- 次の最小スライスは、1つの返答や1つの差分で扱える大きさに留める。
